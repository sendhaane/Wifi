# Wi-Fi Networking Assignments

This repository contains a structured collection of assignments covering IEEE 802.11 (Wi-Fi) concepts from fundamentals to advanced topics.

---

## Modules Covered

### Module 1 – Wi-Fi Basics

* Wi-Fi standards and generations
* Frequency bands and channels
* BSS, ESS, and topology
* Access Point functionalities

---

### Module 2 – WLAN Architecture

* Split MAC architecture
* CAPWAP protocol and tunnels
* Lightweight vs Autonomous APs
* WLC modes and deployment

---

### Module 3 – PHY Layer

* 802.11 PHY standards
* DSSS, FHSS, OFDM, OFDMA
* Modulation techniques
* MIMO, MU-MIMO
* PPDU, PLCP, PMD

---

### Module 4 – MAC Layer

* MAC frame structure
* Management, Control, Data planes
* Association and scanning
* Power saving mechanisms
* Aggregation and Block ACK

---

### Module 5 – Modern Wi-Fi Technologies

* Wi-Fi 6, 6E, and Wi-Fi 7
* OFDMA, TWT, MLO
* 6 GHz band
* Roaming (802.11k, 802.11v, 802.11r)

---

### Module 6 – Wi-Fi Security

* Authentication vs Encryption
* WEP, WPA, WPA2, WPA3
* 4-way handshake
* 802.1X and enterprise security

---
